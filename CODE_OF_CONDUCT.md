CODE OF CONDUCT
Purpose

This project is maintained by Balamurugan Dhandapani (Balamurugan D).

This Code of Conduct establishes expected standards for communication and behavior within the project's GitHub repository, issues, discussions, and other project-related communication channels.

Expected Behavior

Participants are expected to:

Communicate respectfully and professionally;
Avoid harassment, threats, discrimination, or abusive behavior;
Provide constructive feedback;
Respect the project's ownership and licensing terms;
Respect the intellectual-property rights of the Copyright Owner and third parties;
Avoid posting confidential or sensitive information;
Follow applicable GitHub rules and policies.
Prohibited Behavior

The following behavior is not permitted:

Harassment or abusive conduct;
Threats or intimidation;
Spam;
Malicious activity;
Unauthorized access attempts;
Deliberate disruption of the project;
Posting private or sensitive information;
Impersonating the project owner;
Misrepresenting authorship or ownership;
Unauthorized copying or redistribution of project materials.
Intellectual Property

Participation in the repository does not grant ownership or permission to use the project's proprietary materials.

All copyright and intellectual-property rights remain subject to LICENSE.md.

Enforcement

The project owner may remove content, close discussions, restrict participation, or take other appropriate action in response to violations of this Code of Conduct, subject to applicable law and platform policies.
